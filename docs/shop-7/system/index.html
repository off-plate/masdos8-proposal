Shop 7, the web guideline

Every token and every component this site owns, in every state, on one page. A screen only ever uses what is on this page, and anything new is added here first. The components below are the live ones, pulled from shop-7/app.css, so this page cannot drift away from the site.

Colour

The gold is sampled from the MasDos8 logo, the scissors and the lettering on their own sign, so it belongs to the shop rather than to a template. Everything else is a warm near-black and a warm off-white. There is one accent and it never becomes a gradient.

One rail, one gutter. The page margin is --pad and the shell is --shell: 1720px, and every block on every page starts at that same x. No section indents itself, and no column centres itself inside the rail.

Square by default. The pill radius is allowed on three named things and nothing else may borrow it: buttons, the floating navigation, and the price tags in the hero. Cards, panels, photographs and the booking sheet are square corners.

Shadow, ceiling two

Hairlines separate; shadows only lift a thing that genuinely floats over the page. There are exactly two in the site: the hero price tags at 0 14px 34px rgba(0,0,0,.5) and the reservation badge at 0 14px 40px rgba(217,164,65,.32). A card does not get one.

One signature gesture

Gold buttons tilt as they lift, and the two outline buttons tilt the other way. That is the whole personality of the motion, and it is why nothing else needs a flourish. Every animation is off under prefers-reduced-motion.

Photography

Photographs are sized by grid span, never by aspect ratio, so no tile ever lands half a row out. The gallery runs on twelve columns with four spans: the default third, the tall third, the half and the quarter. Every image is desaturated a quarter at rest and comes back to full colour under the cursor, which is how the page shows you it is interactive without a single icon.

Fields and slots

Only the booking sheet takes input, so there is exactly one field treatment and one time slot. A slot has four states and all four are below, including the one that matters most: a time somebody else already took. The sheet itself is one script, app.js, opened from a Reserve button, the badge, or a price row on any of the site's six pages. Each page sets its own service list and confirmation wording through three page-level variables read once at the top of app.js, so the barbershop, the tattoo studio and permanent makeup each quote their own prices without three copies of the flow.

The one-edit test

The client asks for a change. How many places does it take? If the honest answer is more than one, the system is wrong and every future request carries the same tax.

The requestEditsWhere
Make every gold button red1--g in app.css
Change the body typeface1The 'Su' face, one @font-face pair
Make prices a different colour1--g2, which every price already uses
Round the corners on everything1There is one radius rule outside the pills
Widen the page1--shell
Slow every animation down1--ez, and the durations that read from it
Add a fourth service to the price list1One .sr row, which brings its own photograph and booking entry
A page never owns a component

If a new page needs something this list does not have, it is added here first and used there second. That is what stops the About page and the home page ending up with two versions of the same card.
